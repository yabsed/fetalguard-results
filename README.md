# FetalGuard AI — Research Outputs

Research materials on predicting expert abnormality labels from five-minute cardiotocography (CTG) recordings using 28 waveform features, with comparisons to small convolutional neural networks. The analysis covers feature contributions, smoothing, alarm thresholds, generalization across sites, and the relationship between expert readings and birth outcomes.
